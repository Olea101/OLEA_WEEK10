This program enhances the Week 9 **Tricycle** project by incorporating OOP concepts: Inheritance, Polymorphism, Abstract Classes/Interfaces, and Mixins.

## Features & Criteria Met (100 Pts)
- **Inheritance**: `PassengerTricycle` and `CargoTricycle` extend the base `Tricycle` class.
- **Polymorphism**: Overridden `honk()` and `kickstartEngine()` methods demonstrate custom behaviors in derived classes.
- **Abstract Class / Interface**: `Maintainable` abstract class mandates a `serviceEngine()` method.
- **Mixin**: `GPSNavigable` mixin added to `CargoTricycle` using the `with` keyword.
